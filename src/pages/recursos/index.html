Aprende primero, utiliza después

Los recursos de EDUCA CIBER están pensados para acompañar a los contenidos de aprendizaje. Una checklist permite revisar una situación; una guía ayuda a seguir una secuencia; una infografía resume diferencias o señales que conviene recordar.

No queremos convertir esta sección en una carpeta de archivos sin contexto. Cada material debe explicar para qué sirve, cuándo utilizarlo y con qué contenido está relacionado. Así podrás ampliar la información cuando lo necesites y volver a la explicación completa si tienes dudas.

Material preparado para utilizar

Cuando un recurso se publique como documento descargable, se indicará su formato y la fecha de revisión. Mientras tanto, algunos materiales se ofrecen directamente como páginas web imprimibles desde el navegador. Puedes guardarlos como referencia o imprimirlos para consultarlos más adelante.

Los materiales se irán incorporando a medida que estén revisados y relacionados con una explicación formativa. Si un tema todavía no dispone de recurso, podrás acudir a su área de aprendizaje para consultar los conceptos que ya están disponibles.
