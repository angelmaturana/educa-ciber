Cómo utilizar esta checklist

Lee cada pregunta antes de responder al mensaje o abrir el enlace. No necesitas demostrar que el mensaje es fraudulento para detenerte: basta con que exista una duda razonable para verificar la solicitud por otro canal.

Comprueba el remitente y el contexto, pero recuerda que ambos pueden imitarse. Un logotipo, un nombre conocido o una conversación anterior no garantizan que el mensaje sea auténtico. Tampoco basta con fijarse únicamente en errores ortográficos: algunos mensajes fraudulentos están bien redactados.

Si la comunicación solicita una contraseña, un código de verificación o datos bancarios, no los facilites desde el enlace recibido. Entra por tu cuenta en la aplicación o web oficial y comprueba si existe alguna notificación real.

Si sigues teniendo dudas

No respondas ni reenvíes el mensaje como si fuera fiable. Puedes consultar la guía de phishing para conocer más señales y revisar la documentación de referencia de INCIBE.

Para revisar webs, adjuntos y códigos QR, consulta las lecciones sobre webs falsas, enlaces y archivos sospechosos e ingeniería social.
