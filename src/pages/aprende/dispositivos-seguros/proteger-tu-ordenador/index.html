Proteger tu ordenador: cuenta estándar, antivirus, copias.

La mayoría de infecciones ocurren porque usamos cuenta de administrador para todo. Cambia a cuenta estándar y reduce el impacto de cualquier malware.

Nivel básicoPara todos5 min · Lo esencial
Qué debes recordarUsa cuenta estándar para el día a día. Solo usa administrador para instalar software de confianza. El antivirus integrado + cortafuegos + copias cubren lo básico.

5 MIN · Lo esencial

El principio de menor privilegio dice: dale a cada usuario (y a ti mismo) solo los permisos mínimos que necesita. En Windows, macOS y Linux, eso significa:

  • Cuenta estándar (usuario) para uso diario: navegar, correo, documentos, apps. No puede instalar software del sistema, cambiar ajustes críticos, tocar archivos de otros usuarios.
  • Cuenta administrador solo para: instalar programas de confianza, actualizar drivers, cambiar configuración de red/seguridad, gestionar otros usuarios.

Si malware entra mientras usas cuenta estándar, no puede instalarse en el sistema, ni modificar el arranque, ni desactivar el antivirus. El daño se limita a tus archivos (por eso importan las copias).

La idea clave

Usa cuenta estándar para el día a día. Solo usa administrador para instalar software de confianza. El antivirus integrado + cortafuegos + copias cubren lo básico.

Qué configurar hoy mismo

01Crea cuenta estándar

Windows: Configuración > Cuentas > Otros usuarios > Agregar > "No tengo datos de inicio de sesión" > Usuario sin cuenta Microsoft. macOS: Preferencias > Usuarios > + > Estándar.

02Usa la estándar a diario

Inicia sesión con la estándar. Cuando pida contraseña de admin, introdúcela conscientemente (tú la pediste para instalar algo).

03Antivirus integrado activo

Windows Defender (Microsoft Defender), XProtect (macOS), ClamAV/integrado (Linux). No hace falta pagar por uno extra; el integrado está certificado y es ligero.

04Cortafuegos (firewall) encendido

Bloquea conexiones entrantes no solicitadas. Windows: Defender Firewall. macOS: Cortafuegos en Preferencias > Seguridad. Linux: ufw/firewalld.

05Copias de seguridad automáticas

Regla 3-2-1: 3 copias, 2 soportes, 1 fuera (nube/USB en otro sitio). Windows: Historial de archivos / Copia de seguridad. macOS: Time Machine. Linux: rsync/Borg/TimeShift.

15 MIN · Pasos para configurar tu ordenador seguro

  1. Crea la cuenta estándar

    Si ya eres admin, crea un usuario nuevo "Estándar" y pásate a él. Deja la cuenta admin solo para mantenimiento.

  2. Verifica antivirus + firewall

    Windows: Seguridad de Windows > Protección contra virus > Administrar configuración (todo ON). Firewall: redes pública/privada ON.

  3. Configura copias automáticas

    Conecta disco USB o configura nube (OneDrive, Google Drive, iCloud, Nextcloud). Programa: diaria para documentos, semanal para sistema.

  4. Actualizaciones automáticas

    Windows Update / App Store / gestor de paquetes: automáticas. Incluye: sistema, navegador, Office, drivers, firmware.

  5. Desactiva lo innecesario

    Servicios que no uses (compartir archivos, escritorio remoto, Bluetooth si no lo usas). Menos superficie de ataque.

EJEMPLO FICTICIO

Cuenta ADMIN: Malware se ejecuta con privilegios totales → cifra C:\Windows, desactiva Defender, borra copias de sombra, instala rootkit → PC inutilizable.

Cuenta ESTÁNDAR: Malware se ejecuta con privilegios de usuario → cifra SOLO tus documentos (Escritorio, Descargas, Documentos) → NO toca sistema, NO desactiva Defender, NO borra copias de sombra → Restauración desde copia = 15 min.

LA DIFERENCIA: PRIVILEGIOS
Tus archivos personales se cifran en ambos casos (por eso importan las copias). Pero en cuenta estándar, el SISTEMA sobrevive.
MALWARE ENTRA→CUENTA ADMIN: CONTROL TOTAL→SISTEMA DESTRUIDO→CUENTA ESTÁNDAR: SOLO ARCHIVOS USER→SISTEMA INTACTO

Y si ya usas cuenta admin para todo

No formatees. Crea usuario estándar nuevo, pásate a él, y usa la vieja solo cuando el sistema pida contraseña de administrador. En Windows: Configuración > Cuentas > Cambiar tipo de cuenta > Estándar (para tu usuario actual) — pero mejor crear uno limpio.

Ponte a prueba

Caso práctico

Descargas un instalador de "actualización de driver" de una web rara. Te pide contraseña de administrador. ¿Se la das?

¿Qué opción es la más prudente?
NO. Si estás en cuenta estándar, el sistema te pide la contraseña de admin. Eso es una señal: ¿por qué un driver necesita permisos de sistema? Cancela. Descarga drivers solo de la web oficial del fabricante (NVIDIA, AMD, Intel, web del portátil).

La petición de contraseña de admin es tu momento para parar y pensar.

Caso práctico

Tu antivirus (Windows Defender) salta con una alerta: "Amenaza detectada: Trojan:Win32/...". ¿Qué haces?

¿Qué harías en este caso?
Deja que lo ponga en cuarentena/elimine. No lo restaures. Pasa un análisis completo (Windows Defender > Análisis completo). Cambia contraseñas desde otro dispositivo si la alerta era de spyware/keylogger.

Defender actúa solo. La alerta significa que LO DETECTÓ y LO BLOQUEÓ. No entres en pánico, pero toma en serio el análisis completo.

Preguntas frecuentes

¿Puedo seguir instalando programas si uso cuenta estándar?

Sí. Cuando el instalador pide permisos, Windows/macOS/Linux te muestra un diálogo pidiendo la contraseña de la cuenta administrador. La introduces, el programa se instala, y vuelves a tu cuenta estándar. Es un paso extra de 5 segundos que te protege.

¿El antivirus integrado (Defender/XProtect) es suficiente?

Para la inmensa mayoría de usuarios, SÍ. Defender puntúa top en tests independientes (AV-TEST, AV-Comparatives), es gratis, ligero, sin publicidad, y se actualiza solo. Los antivirus de pago añaden funciones extra (VPN, gestor contraseñas, control parental) que ya tienes en otras herramientas.

¿Qué pasa con Linux? ¿Necesita antivirus?

Linux de escritorio tiene menos malware, pero no es inmune. ClamAV para escaneos puntuales, pero lo importante es: actualizaciones automáticas (unattended-upgrades), firewall (ufw), no root para uso diario, solo repositorios oficiales, permisos mínimos. El principio de menor privilegio es nativo en Linux.
