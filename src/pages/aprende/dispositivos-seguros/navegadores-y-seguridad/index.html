Navegadores y seguridad: modo incógnito, extensiones, avisos.

Tu navegador es tu puerta a Internet. Configúralo bien: modo incógnito (qué SÍ y NO hace), extensiones que protegen, avisos que no debes ignorar, gestor integrado.

5 MIN · Lo esencial

El navegador (Chrome, Firefox, Edge, Safari, Brave, Vivaldi...) es el software que más riesgo gestiona: ejecuta código de webs desconocidas, guarda credenciales, cookies, historial, permisos. Configurarlo bien es defensa crítica.

La idea clave

Modo incógnito = sin historial local. NO = invisible para web, ISP, empleador, red. Para privacidad real: VPN + HTTPS + bloqueadores + navegador enfocado en privacidad.

Modo incógnito / privado: qué SÍ y qué NO hace

SÍ hace (local)

• No guarda historial de navegación
• No guarda cookies / datos de sitio al cerrar ventana
• No guarda formularios / contraseñas nuevas
• No sincroniza con cuenta (si no inicias sesión)
• Aísla sesión de la normal (cookies separadas)

NO hace (red / web / sistema)

• NO oculta tu IP (web, ISP, red, VPN ven tu IP real)
• NO evita fingerprinting (resolución, fuentes, batería, canvas, audio, headers)
• NO impide tracking por cuenta (si inicias sesión en Google/Facebook en incógnito, TE RASTREAN)
• NO cifra tu tráfico (ISP ve dominios, DNS, salvo DNS-over-HTTPS/VPN)
• NO protege de malware / phishing / descargas maliciosas
• NO oculta actividad a empleador / escuela (red corporativa / MDM / proxy lo ve todo)

Extensiones de seguridad (imprescindibles)

01uBlock Origin (bloqueador)

Bloquea anuncios, trackers, malware domains, coin miners, popups. Ligero, open source, listas actualizadas. Chrome/Edge/Firefox/Safari (extensión). "Modo medio" para usuarios avanzados (bloquea 3rd-party scripts/frames).

02HTTPS-Only / HTTPS-First

Fuerza HTTPS en todo. Chrome/Edge: HTTPS-First Mode (flags). Firefox: HTTPS-Only Mode (about:config). Safari iOS 15+: Requerir HTTPS. Evita SSL stripping (degradar a HTTP).

03Bitwarden / 1Password / KeePassXC (gestor)

Extensión oficial del gestor. Autocompleta SOLO en dominio correcto (protege phishing). Genera frases únicas. 2FA integrado (TOTP). Sincroniza bóveda.

04Privacy Badger / DuckDuckGo Privacy Essentials

Aprende y bloquea trackers invisibles (heurística). Complemento a uBlock. DuckDuckGo añade: fuerza HTTPS, calificación privacidad web, bloqueo trackers email.

05Malwarebytes Browser Guard / Bitdefender TrafficLight

Capa extra: bloquea phishing conocido, malware domains, tech support scams, exploits. Basado en inteligencia de amenazas de la empresa. Gratis.

Avisos del navegador: NO los ignores

Cuando el navegador muestra una advertencia, es tu última barrera técnica. Léela.

  1. "Conexión no privada / NET::ERR_CERT_..."

    Certificado inválido (expirado, autofirmado, dominio no coincide, CA no confiable). Puede ser MITM (te interceptan) o error del sitio. NO continúes. Espera o contacta por otro canal.

  2. "Sitio engañoso / Phishing / Malware" (Safe Browsing)

    Google Safe Browsing / Microsoft Defender SmartScreen / Firefox Phishing Protection detectaron phishing, malware, ingeniería social. NO entres. Reporte falso si crees que es error.

  3. "La conexión no es segura / HTTP" (icono candado tachado / info)

    Web en HTTP (sin TLS). Todo va en claro. No introduzcas NADA (pass, tarjeta, datos). Busca versión HTTPS o alternativa.

  4. "Descarga peligrosa / Archivo poco frecuente"

    SmartScreen / Safe Browsing / heurística del navegador detectan ejecutable sospechoso, firma inválida, reputación baja. Cancela. Verifica en VirusTotal.

  5. "Quiere acceder a: cámara / micrófono / ubicación / notificaciones"

    Pide permiso SOLO si la función LO REQUIERE (videollamada = cámara/mic; mapa = ubicación; web de noticias = NO). "Preguntar cada vez" > "Permitir siempre".

Gestor de contraseñas integrado vs dedicado

Integrado (Chrome, Edge, Firefox, Safari)

✅ Gratis, cómodo, sincroniza con cuenta (Google, Microsoft, Firefox, iCloud)
✅ Autocompleta en apps móviles (Android: Autofill; iOS: Contraseñas)
❌ Menos funciones (auditoría pass, 2FA, compartir seguro, alertas brecha)
❌ Vendor lock-in (difícil migrar)
❌ Chrome: no cifra bóveda con pass maestra propia (usa credenciales OS)

Dedicado (Bitwarden, 1Password, Proton Pass, NordPass)

✅ Cifrado E2E con pass maestra TUYA (zero knowledge)
✅ Auditoría: pass débiles, reutilizadas, expuestas, 2FA faltante
✅ 2FA integrado (TOTP), passkeys, compartir seguro (organización/familia)
✅ Alertas brecha (Have I Been Pwned), informes salud
✅ Multiplataforma, open source (Bitwarden, Proton), portable
❌ Pago para funciones avanzadas (1Password, Proton Pass Plus, NordPass)

15 MIN · Configura tu navegador seguro (hoy)

  1. Instala uBlock Origin + HTTPS-Only Mode

    Chrome/Edge: Extensiones > uBlock Origin. Flags: HTTPS-First Mode. Firefox: uBlock Origin + about:config > dom.security.https_first = true. Safari: uBlock Origin (Mac) / 1Blocker (iOS) + Ajustes > Safari > Requerir HTTPS.

  2. Elige gestor: integrado o dedicado

    Si ya usas dedicado (Bitwarden, 1Password): desactiva guardado en navegador (Ajustes > Contraseñas > "Ofrecer guardar contraseñas" OFF). Usa SOLO extensión del gestor. Si no tienes: empieza con integrado + migra luego.

  3. Privacidad: bloquea 3rd-party cookies + fingerprinting

    Chrome/Edge: Ajustes > Privacidad > Cookies > Bloquear cookies de terceros (ON). Firefox: Protección estricta (ON) > about:config > privacy.resistFingerprinting = true. Safari: Prevención de seguimiento inteligente (ON) + Ocultar IP (iCloud+).

  4. DNS seguro (DoH / DoT)

    Chrome/Edge/Firefox: Ajustes > Privacidad > DNS seguro > "Usar proveedor seguro" (Cloudflare 1.1.1.1, NextDNS, Google). NextDNS permite bloqueo personalizado (ads, trackers, malware, porn, typosquatting).

  5. Actualizaciones automáticas + reinicio rápido

    Chrome/Edge/Firefox: actualizan en fondo. Reinicia cuando pida (icono actualización). Safari: via Actualización de software (macOS/iOS). No pospongas días.

EJEMPLO FICTICIO

Cree que "nadie ve lo que hago".
Realidad:
• Firewall/proxy corporativo: ve todos los los dominios (DNS, SNI TLS, HTTP Host)
• MDM / agente en portátil: ve historial, capturas, keylogs
• ISP de la empresa: ve IP, volumen, horas
• Web visitada: ve IP corporativa, fingerprinting, cuenta si login
• Incógnito: solo evita historial LOCAL en ESE navegador

INCÓGNITO ≠ ANONIMATO. RED CORPORATIVA = VISIBILIDAD TOTAL.
Para privacidad real en red ajena: VPN personal (kill switch) + navegador anti-fingerprint (Tor Browser, Brave, Mullvad Browser) + HTTPS-Only + uBlock.
ABRES INCÓGNITO→CREES PRIVACIDAD→RED / ISP / WEB / EMPLEADOR→VEN TU IP, DOMINIOS, FINGERPRINT→SOLO HISTORIAL LOCAL SE BORRA

Navegadores enfocados en privacidad (opcional)

  • Brave: Chromium + Shields (bloquea ads/trackers/fingerprinting nativo) + Tor window + IPFS + Wallet. Recompensas BAT (opcional).
  • Firefox (hardened / arkenfox / librewolf): Gecko + configuración estricta (about:config) + contenedores multi-cuenta + extensiones potentes. Libre, open source.
  • Tor Browser: Firefox + red Tor (3 saltos, IP oculta) + NoScript + anti-fingerprinting extremo. Lento, para alta necesidad de anonimato.
  • Mullvad Browser: Firefox + configuración Mullvad (anti-fingerprint, sin telemetría) + diseñado para usar con VPN Mullvad. Sin cuenta, sin sync.
  • Safari (iOS/macOS + iCloud+): ITP (Intelligent Tracking Prevention) + Ocultar IP (relay privado) + Reporte privacidad + Extensiones (1Blocker, Ka-Block). Buen equilibrio usabilidad/privacidad.

Ponte a prueba

Caso práctico

Abres modo incógnito en Chrome, entras a Gmail (inicias sesión), buscas en Google, ves YouTube. Cierras ventana. ¿Qué sabe Google de ti?

¿Qué opción es la más prudente?
todo lo que hiciste INICIANDO SESIÓN. Incógnito no oculta actividad a la cuenta. Google vincula: búsquedas, videos, IP, fingerprint, dispositivo, ubicación. Lo que NO guarda: historial LOCAL en TU Chrome (pero sí en "Mi actividad" de Google).

Incógnito + cuenta iniciada = privacidad CERO frente al proveedor de la cuenta.

Caso práctico

Tu navegador avisa: "Esta web intenta cargar scripts de fuentes no seguras (mixed content)". ¿Permitir?

¿Qué harías en este caso?
NO. Mixed content = página HTTPS que carga recursos (imágenes, scripts, iframes) por HTTP. Esos recursos viajan en claro: pueden ser modificados (inyectar malware, robar cookies, redirigir). La web está mal configurada. No permitas. Si es tu banco/servicio crítico: avisa a su soporte.

Chrome/Edge/Firefox/Safari bloquean mixed content activo (scripts/iframes) por defecto. Imágenes/estilos pasivos a veces se permiten (con avisos). No fuerces.

Preguntas frecuentes

¿Borrar historial / cookies me hace anónimo?

NO. Borra datos LOCALES. Tu IP, fingerprint, cuentas iniciadas, ISP, webs visitadas, red corporativa: todo sigue viéndote. Anonimato requiere: VPN/Tor + navegador anti-fingerprint + sin cuentas + HTTPS + DNS seguro + comportamiento cuidadoso.

¿Qué navegador es "el más seguro"?

No hay uno solo. Para usuario general: Safari (iOS/macOS + iCloud+) o Firefox (hardened) o Brave. Para alta privacidad: Tor Browser / Mullvad Browser + VPN. Para empresarial: Edge (integración Defender, políticas de grupo) o Chrome Enterprise. Lo importante: CONFIGURACIÓN (uBlock, HTTPS-Only, gestor, DNS seguro, actualizaciones) > MARCA.

¿Las extensiones pueden ser peligrosas?

SÍ. Extensiones maliciosas / comprometidas roban datos, inyectan ads, minan crypto, secuestran sesiones. Solo instala de: tienda oficial, desarrollador verificado, código abierto (GitHub), permisos mínimos, actualizaciones recientes. Revisa permisos: "Leer y cambiar todos tus datos en los sitios web" = acceso total. Menos extensiones = menos riesgo.
