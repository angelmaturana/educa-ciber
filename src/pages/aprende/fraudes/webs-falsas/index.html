Webs falsas: el candado no basta.

Ver el candado HTTPS te da falsa seguridad. Una web fraudulenta también lo tiene. Aprende a verificar el dominio y detectar la copia.

Nivel básicoPara todos5 min · Lo esencial
Qué debes recordarHTTPS cifra la conexión, no certifica quién está al otro lado. Verifica siempre el dominio antes de confiar.

5 MIN · Lo esencial

Cuando ves el candado en la barra del navegador, significa que la conexión está cifrada (TLS/SSL). Nadie puede espiar lo que envías o recibes. Pero el candado NO verifica quién está al otro lado: una web fraudulenta también puede tener HTTPS. Cualquiera puede obtener un certificado gratis (Let's Encrypt) para su dominio.

La idea clave

HTTPS cifra la conexión, no certifica quién está al otro lado. Verifica siempre el dominio antes de confiar.

Qué verifica y qué NO el candado

01Cifra la conexión

Tus datos viajan encriptados entre tu navegador y el servidor.

02NO verifica la identidad

Cualquiera puede obtener un certificado para su dominio, incluso estafadores.

03NO garantiza seguridad

La web puede tener malware, phishing o ser una copia de marca.

04Dominio ≠ organización

banco-ejemplo.com no es el banco, aunque tenga candado.

05Certificados gratuitos

Let's Encrypt y otros emiten certificados gratis; tener uno no cuesta nada.

15 MIN · Aprende a comprobar la web

El candado es necesario, pero no suficiente. Antes de confiar, verifica lo siguiente:

  1. Mira el dominio completo

    Lee la URL entera. ¿Coincide exactamente con la organización oficial? Cuidado con subdominios (seguridad.banco.com.malicioso.com).

  2. Busca señales de suplantación

    Errores ortográficos, diseño descuidado, urgencia, peticiones de datos sensibles.

  3. Verifica por otro canal

    Si dudar, contacta con la entidad por teléfono o app oficial, no por enlaces del mensaje.

  4. Usa herramientas de reputación

    Extensiones o servicios que avisan de webs conocidas como fraudulentas.

Ponte a prueba

Caso práctico

Entras en una web con candado HTTPS que dice ser tu banco. La URL es banco-seguridad-clientes.com. ¿Qué haces?

¿Qué opción es la más prudente?
No introduzcas credenciales. El dominio no es el oficial de tu banco. Entra en la app o escribe la URL oficial que ya conoces.

El subdominio o dominio similar es el truco clásico. El candado solo cifra, no valida la identidad.

Caso práctico

Recibes un email con un enlace a una web con HTTPS que pide tu contraseña. El remitente parece tu banco. ¿Es seguro?

¿Qué harías en este caso?
No. HTTPS solo cifra la conexión. El phishing también usa HTTPS. Verifica el dominio y entra por tu cuenta en la app oficial.

El certificado TLS lo puede tener cualquiera. Lo que importa es el dominio, no el candado.

Preguntas frecuentes

Si una web tiene el candado verde o el nombre de la empresa en la barra, ¿es segura?

Los navegadores ya no muestran el nombre de la empresa en la barra (certificados EV). El candado solo indica cifrado. Verifica siempre el dominio.

¿Significa HTTPS que la web no tiene virus?

No. HTTPS protege la transmisión, no el contenido. Una web con HTTPS puede distribuir malware o ser phishing.

¿Cómo sé si un certificado es de confianza?

Los navegadores confían en certificados emitidos por autoridades reconocidas. Pero cualquiera puede obtener uno para su dominio. Lo importante es el dominio, no el certificado.
