Descargas seguras: tiendas oficiales vs pirata.

El software pirata, cracks y keygens son la principal vía de entrada de malware. Descarga solo de fuentes oficiales y verifica antes de ejecutar.

Nivel básicoPara todos5 min · Lo esencial
Qué debes recordarLo "gratis" que no es oficial sale caro: troyanos, ransomware, miners, spyware. Tienda oficial / web del desarrollador = única fuente segura.

5 MIN · Lo esencial

Cuando buscas "descargar gratis" un programa de pago, un crack, un keygen o una "versión pro" modificada, estás abriendo la puerta a:

  • Troyanos: dan control remoto a atacantes (robo de contraseñas, 2FA, archivos, cámara, micrófono).
  • Ransomware: cifra tus archivos y pide rescate. El "ahorro" de 50 € te cuesta todos tus datos.
  • Cryptominers: usan tu CPU/GPU para minar criptomonedas. PC lentísimo, factura eléctrica alta, hardware dañado.
  • Spyware / keyloggers: graban teclas, capturan pantalla, roban credenciales bancarias, criptomonedas.
  • Adware / hijackers: inyectan anuncios, cambian buscador, redirigen a webs de afiliados.
La idea clave

Lo "gratis" que no es oficial sale caro: troyanos, ransomware, miners, spyware. Tienda oficial / web del desarrollador = única fuente segura.

Dónde descargar SEGURO (orden de confianza)

1. Tienda oficial del sistema

Microsoft Store (Windows), Mac App Store (macOS), Play Store (Android), App Store (iOS), repositorio de tu distro Linux (apt, dnf, Flatpak, Snap). Revisión automática + humana + revocación remota.

2. Web oficial del desarrollador

Ej: vlc.org, obsproject.org, 7-zip.org, notepad-plus-plus.org, rufus.ie, veracrypt.fr, signal.org, bitwarden.com. Verifica: HTTPS, dominio correcto, firma digital / hash (SHA256) publicado.

3. GitHub Releases / GitLab / SourceForge (oficiales)

Proyectos open source: libera en su repo oficial. Verifica: cuenta verificada del autor, firma GPG, hashes SHA256 en la página de releases.

4. Gestores de paquetes de confianza

Chocolatey / Winget / Scoop (Windows), Homebrew (macOS), apt/dnf/pacman (Linux), Flatpak (Flathub), Snap (Snapcraft). Automatizan verificación de hashes y firmas.

Qué EVITAR (fuentes de riesgo alto)

01Webs de "descargas gratis" / "softonic" / "uptodown" / "filehippo"

Inyectan instaladores con adware, toolbars, cambios de buscador, spyware. El programa original viene "envuelto" en basura.

02Cracks / keygens / parches / loaders

Son ejecutables diseñados para saltar protecciones. El 90 %+ llevan malware (troyano, ransomware, miner). Los antivirus a menudo no detectan lo nuevo.

03Torrent / P2P / warez / forums de "scene"

ISO de Windows/Office "preactivados", juegos "crackeados", suites "pro". vectores masivos de ransomware, rootkits, botnets.

04Anuncios en buscadores ("Descargar X gratis")

El primer resultado de "descargar photoshop gratis" suele ser malware. Los atacantes compran anuncios para aparecer arriba.

05Enlaces por WhatsApp / Telegram / Discord / email

"Mira este programita que te pasa X". Archivo .exe, .apk, .zip con .exe dentro. El contacto puede tener la cuenta comprometida.

15 MIN · Verifica ANTES de ejecutar (checklist)

  1. ¿Fuente oficial?

    Tienda del sistema / web del desarrollador / repo oficial. NO webs de terceros, NO cracks, NO torrents.

  2. ¿Hash coincide? (SHA256)

    El desarrollador publica el hash. Tú calculas el del archivo descargado (Windows: `certutil -hashfile archivo.exe SHA256`, macOS/Linux: `sha256sum archivo`). Si no coincide = NO ejecutes.

  3. ¿Firma digital válida? (Windows)

    Botón derecho > Propiedades > Firma digital. Debe mostrar editor verificado (ej. "VideoLAN", "OBS Project", "Microsoft Corporation"). "No firmado" o editor raro = sospechoso.

  4. ¿VirusTotal limpio?

    Sube el archivo a virustotal.com (gratis, 70+ motores). 0 detecciones = buena señal. Algunas = revisa cuáles (falsos positivos vs reales).

  5. ¿Instalador limpio?

    Ejecuta instalador en máquina virtual / sandbox (Windows Sandbox, VirtualBox, Firejail) si dudaras. Observa: ¿pide admin innecesario? ¿instala "ofertas" extra? ¿cambia navegador?

Ponte a prueba

Caso práctico

Buscas "Windows 11 Pro activado gratis". El primer resultado es una ISO de 5 GB en Google Drive. La descargas, la montas y ejecutas el setup. ¿Riesgo?

¿Qué opción es la más prudente?
MUY ALTO. ISOs "preactivadas" modifican archivos de sistema, inyectan claves KMS, desactivan Defender, instalan puertas traseras. No hay forma de saber qué más traen. Compra licencia oficial (15-20 € en webs de claves legítimas) o usa Linux (gratis, seguro).

Windows 10/11 se puede usar sin activar (marca de agua, sin personalización). Es legal y seguro.

Caso práctico

Descargas un instalador de "Driver Booster Pro crack" de una web conocida de cracks. Tu antivirus (Defender) no salta. Lo ejecutas. ¿Estás a salvo?

¿Qué harías en este caso?
NO. Defender detecta lo CONOCIDO. Cracks nuevos (0-day) pasan. El antivirus no es infalible. Has ejecutado código con privilegios de admin de fuente no confiable. Pasa análisis completo offline (Windows Defender > Análisis sin conexión) y considera restaurar punto anterior / reinstalar.

La ausencia de alerta no garantiza seguridad. El riesgo ya se tomó.

Preguntas frecuentes

¿Puedo confiar en webs como Softonic, Uptodown, FileHippo?

NO recomendadas. Su modelo de negocio: envolver instaladores legítimos con sus propios "download managers" que instalan adware, toolbars, cambian buscador, recogen datos. Mejor: web oficial del desarrollador o tienda del sistema.

¿Qué hay de los "repacks" de juegos (FitGirl, DODI, ElAmigos)?

Son "conocidos" en la escena y suelen ser limpios... PERO: siguen siendo piratería, modifican archivos, desactivan protecciones, y no hay garantía absoluta. Un repack comprometido = malware con firma de confianza. Riesgo alto. Compra en Steam / GOG / Epic (ofertas frecuentes) o usa juegos gratis (F2P, Epic gratis semanal, itch.io).

¿Linux es inmune a esto?

NO. Hay malware para Linux (rootkits, ransomware ESXi, miners, botnets IoT). Pero: instalas de repositorio oficial (firmado), no necesitas cracks (todo open source), y el modelo de permisos limita el daño. La higiene de descargas aplica igual: solo fuentes oficiales, verifica firmas/GPG.
