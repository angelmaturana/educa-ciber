Borrado seguro

intermediotodos5 min · Lo esencial
Qué debes recordarPapelera de reciclaje, Shift+Supr, formateo rápido: nada de eso borra datos. Solo sobrescritura múltiple (HDD) o comando TRIM/SE (SSD) o cifrado previo + borrado de clave (moderno) garantizan irrecuperabilidad.

5 MIN · Lo esencial

Cuando «borras» un archivo, el sistema operativo solo quita la entrada del índice (tabla de archivos) y marca esos bloques como disponibles. Los datos permanecen en el disco hasta que se sobrescriben. Herramientas de recuperación (Recuva, PhotoRec, TestDisk, R-Studio) los recuperan en minutos. Para borrar realmente: 1) HDD (mecánico): sobrescritura múltiple (estándar DoD 5220.22-M: 3 pasadas; Gutmann: 35 pasadas; NIST SP 800-88: 1 pasada aleatoria verificada es suficiente). Herramientas: shred (Linux), Eraser (Windows), nwipe (arranque), DBAN (antiguo, solo HDD). 2) SSD/NVMe/eMMC (flash): la sobrescritura desgasta celdas y no garantiza borrado por wear leveling y over-provisioning. Usa comando nativo: TRIM (Windows: Optimizar unidades, Linux: fstrim/discard, macOS: automático en APFS) + Secure Erase (ATA SECURITY ERASE UNIT / NVMe FORMAT NVM) via nvme-cli, hdparm --security-erase, Parted Magic, o firmware del fabricante. 3) Móviles: cifrado previo (FileVault/BitLocker/LUKS/Android/iOS ya lo hacen por defecto) + restablecimiento de fábrica = borra la clave de cifrado = datos irrecuperables. 4) Nube: borra archivo → papelera → vaciar papelera → versión anterior (si hay versionado) → contactar soporte para purga total (RGPD art. 17). 5) Papel: trituradora cruzada (cross-cut, P-4/P-5) o microcorte (P-6/P-7). Nunca tira a la basura documentos con DNI, cuenta bancaria, contraseñas, firmas.

La idea clave

Papelera de reciclaje, Shift+Supr, formateo rápido: nada de eso borra datos. Solo sobrescritura múltiple (HDD) o comando TRIM/SE (SSD) o cifrado previo + borrado de clave (moderno) garantizan irrecuperabilidad.

Métodos que NO borran (y la gente cree que sí)

01Papelera de reciclaje / Shift+Supr / rm

Solo quitan referencia en filesystem. Datos intactos en disco. Recuperables con PhotoRec/TestDisk en minutos.

02Formateo rápido (Quick Format)

Reescribe tabla de particiones/filesystem, no toca datos. Igual de recuperable.

03Restablecer móvil sin cifrado previo (Android antiguo sin FBE)

Solo marca bloques libres. Flash memory no sobrescribe al instante. Recuperable con herramientas forenses.

04Sobrescribir SSD con herramientas de HDD (shred, DBAN)

Desgasta celdas innecesariamente, wear leveling mueve datos, no garantiza borrado de over-provisioning. Usa Secure Erase nativo.

EJEMPLO FICTICIO

Mi checklist antes de entregar: 1) Backup 3-2-1 verificado. 2) Desvincular cuentas (Microsoft, Apple, Google, BitLocker recovery key). 3) SSD: nvme-cli format /dev/nvme0n1 --ses (Secure Erase) O Parted Magic → Erase Disk → NVMe Format. 4) HDD secundario: nwipe --method=dod --verify (3 pasadas + verificación). 5) Reinstalar Windows/Linux limpio. 6) Verificar: arrancar, ver que no hay datos personales, apagar. 7) Entregar con cargador y caja original.

EJEMPLO FICTICIO. Secure Erase tarda segundos-minutos en NVMe. nwipe en HDD 1TB ~3-6h. Planifica tiempo.

¿Por qué desvincular BitLocker/Find My/iCloud ANTES de borrar? Porque si el comprador activa BitLocker/Find My con su cuenta, el dispositivo queda vinculado a TI. Desvincula: Windows → Configuración → Cuentas → Tu información → Dejar de sincronizar / BitLocker → Desactivar. Mac → Preferencias → Apple ID → Cerrar sesión. Móvil → Ajustes → Tu nombre → Cerrar sesión.

15 MIN · Borrado seguro según tu dispositivo

Identifica tu medio y aplica el método correcto:

  1. SSD / NVMe / eMMC (portátil, móvil, USB-C SSD)

    Windows: Parted Magic (USB booteable) → Erase Disk → NVMe Format / ATA Secure Erase. Linux: nvme format /dev/nvme0n1 --ses=1 (User Data Erase) o nvme format --ses=2 (Cryptographic Erase - instantáneo si hay clave). hdparm --security-erase-enhanced /dev/sdX (SATA SSD). macOS: Utilidad de Discos → Borrar → Seguridad → «Más seguro» (solo HDD) / en SSD: FileVault ON → Reiniciar → Utilidad de Discos → Borrar (APFS + cifrado = borrado criptográfico).

  2. HDD mecánico (disco externo, NAS, PC antiguo)

    Windows: Eraser (click derecho → Eraser → Borrar espacio libre / archivo) o nwipe (USB booteable). Linux: shred -vfz -n 3 /dev/sdX (3 pasadas + cero final) o nwipe --method=dod. macOS: Utilidad de Discos → Borrar → Opciones de seguridad → 3 pasadas (DoD) o 7 pasadas. Verificación: leer sectores aleatorios con dd/hexdump tras borrado.

  3. Móvil / Tablet (Android / iOS)

    Android 10+ (cifrado basado en archivos FBE activado por defecto): Ajustes → Sistema → Restablecer → Borrar todos los datos. iOS 8+ (cifrado hardware + Data Protection): Ajustes → General → Transferir/Restablecer → Borrar contenido y ajustes. Ambos: la clave de cifrado se destruye → datos irrecuperables. Verifica: tras restablecer, configurar como nuevo → comprobar que no hay cuentas / fotos / apps previas.

  4. USB / Tarjeta SD (memoria flash)

    Si es para desechar: destruir físicamente (martillo, taladro, trituradora industrial). Si es para reutilizar: formateo completo (NO rápido) + sobrescritura con shred/nwipe (tratamiento como SSD sin wear leveling complejo) O mejor: cifrar con VeraCrypt/Cryptomator ANTES de usarla, luego borrar contenedor/clave.

  5. Papel y documentos físicos

    Trituradora cruzada (cross-cut, DIN 66399 P-4 mínimo 4x40mm) para DNI, contratos, bancarios, contraseñas, firmas. Microcorte (P-5/P-6/P-7) para alta seguridad. Quemar (seguro, legal en zona permitida) para eliminar trazas químicas. Nunca: tirar a papelera, reciclaje, contenedor calle.

Error frecuente: «formateé el disco antes de venderlo, está limpio»

Formateo rápido = tabla de particiones nueva, datos intactos. Cualquiera con Recuva/PhotoRec recupera fotos, documentos, contraseñas en 10 min. En HDD: usa nwipe/Eraser (3 pasadas). En SSD: usa Secure Erase (nvme-cli, hdparm, Parted Magic). En móvil: restablecer de fábrica (con cifrado previo activado). Verifica siempre: intenta recuperar algo tú mismo antes de entregar.

Ponte a prueba

Caso práctico

Tienes un HDD externo de 2TB con fotos familiares. Lo vas a regalar a un familiar. ¿Cómo lo borras?

¿Qué opción es la más prudente?
Conecta → nwipe (USB booteable Parted Magic) → método DoD 3 pasadas + verificación (--verify). Tarda ~4-6h. Al acabar, formatea NTFS/exFAT limpio. Verifica: intenta recuperar con PhotoRec → 0 archivos. Entrega con confianza.

Caso práctico

Vendes tu iPhone 13. Haces «Borrar contenido y ajustes». ¿Es suficiente?

¿Qué opción es la más prudente?
Sí. iOS cifra por hardware (Secure Enclave + AES-256) desde iPhone 3GS. «Borrar contenido» destruye la clave de cifrado (effaceable storage). Sin clave, los bloques flash son ruido aleatorio. Irrecuperable incluso para Apple/forenses. Verifica: tras borrar, configurar como nuevo → sin fotos, contactos, apps, cuentas.

Preguntas frecuentes

¿Cuántas pasadas son necesarias para HDD modernos?

NIST SP 800-88 Rev. 1 (2014): una pasada aleatoria verificada es suficiente para HDD modernos (post-2001). DoD 5220.22-M (3 pasadas) es estándar heredado, aún aceptado. Gutmann (35 pasadas) es obsoleto (diseñado para MFM/RLL de los 80). Clave: verificación tras escritura (leer y confirmar patrón).

¿El cifrado previo (BitLocker/FileVault/LUKS/Android FBE/iOS Data Protection) sustituye al borrado seguro?

Sí, si la clave se destruye irreversiblemente. Cifrado + borrado de clave (restablecer fábrica, cryptographic erase NVMe, reformatear partición LUKS/BitLocker) = datos irrecuperables. Es más rápido (segundos) y seguro que sobrescritura. Requisito: el cifrado debe estar ACTIVO *antes* de guardar datos sensibles. Si cifras después, los datos en claro previos quedan en sectores no cifrados (remanencia).

¿Cómo borro de forma segura un archivo suelto en Windows sin borrar todo el disco?

Eraser (gratis, open source): click derecho → Eraser → Borrar (sobrescribe clusters del archivo + entrada MFT + espacio libre opcional). SDelete (Sysinternals, CLI): sdelete -p 3 archivo.txt (3 pasadas). PowerShell: cipher /w:C:\ruta\carpeta (sobrescribe espacio libre de la unidad). En Linux: shred -vfz -n 3 archivo. En macOS: rm -P archivo (3 pasadas) o srm (secure rm).
