Tres segundos antes de hacer clic.

Un pequeño hábito puede ayudarte a evitar una decisión precipitada.

DETENTE3″PIENSA · COMPRUEBA · ACTÚA

Antes de pulsar, pregúntate:

  • ¿Esperaba este mensaje?
  • ¿Me están metiendo prisa?
  • ¿Me piden datos o códigos?
  • ¿Puedo verificarlo desde la web o aplicación oficial?
Si algo no encaja, no pulses.

Por qué merece la pena hacer una pausa

Muchos engaños intentan que tomes una decisión rápida. El mensaje puede hablar de un bloqueo, un pago pendiente, una entrega retenida o una actividad inusual. La urgencia busca que no compruebes quién te escribe ni si la petición tiene sentido.

Una pausa breve te permite separar el mensaje de la acción que te pide. No respondas desde el propio mensaje ni uses directamente sus enlaces para identificarte. Si la comunicación parece proceder de un banco, una empresa o un servicio que utilizas, abre la aplicación oficial o busca tú mismo su canal de contacto.

El hábito que queremos recordar

Detente, piensa qué te están pidiendo y comprueba si la solicitud es auténtica. Si no puedes verificarla, no continúes. Comparte esta píldora con alguien a quien pueda ayudar y consulta la explicación completa sobre cómo reconocer el phishing.

Este recordatorio es útil tanto en el móvil como en el ordenador. Si una comunicación te sorprende o te presiona, cambia de canal antes de responder. Una comprobación independiente puede ayudarte a evitar que una emoción momentánea decida por ti.
